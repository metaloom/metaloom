# Cortex Mage-Flow imagegen sidecar. Python 3.10+.

# The version set below is upstream's own tested one (Mage/mage_flow/requirements.txt),
# copied rather than loosened: the text encoder is a *patched* Qwen3-VL, so a
# transformers minor bump is a real risk, not a cosmetic one (see the pin note).
#
# The `mage-flow` package itself is NOT listed here - it is not on PyPI and must be
# installed with --no-deps so it cannot re-resolve these pins (it declares gradio and
# loose torch bounds). setup.sh does that as a second step.
#
# flash-attn is NOT listed here either, and is optional for this sidecar - see README
# ("Attention backend"). It only builds with a matching nvcc and build isolation off.
