The Loom server is distributed as the `metaloom/loom-server` image (JVM and `-native` variants). For a
zero-config first run, use the all-in-one `metaloom/loom-demo` image instead — see
link:../../getting-started/[Getting Started]. The full image list is on link:../../deployment/[Container Images].

== Running with Docker

[source,bash]
----
docker run -d \
  --name loom \
  -p 8092:8092 \
  -p 8091:8091 \
  -p 8989:8989 \
  -e LOOM_DB_HOST=postgres \
  -e LOOM_DB_PASSWORD=secret \
  -e LOOM_INITIAL_PASSWORD=admin123 \
  metaloom/loom-server:latest
----

== Docker Compose

[source,yaml]
----
version: "3.8"
services:
  postgres:
    image: postgres:16
    environment:
      POSTGRES_DB: loom
      POSTGRES_USER: postgres
      POSTGRES_PASSWORD: secret

  loom:
    image: metaloom/loom-server:latest
    depends_on:
      - postgres
    ports:
      - "8092:8092"
      - "8989:8989"
    environment:
      LOOM_DB_HOST: postgres
      LOOM_DB_PASSWORD: secret
      LOOM_INITIAL_PASSWORD: admin123
----

To add processing, run one or more link:../../cortex/containers/[Cortex workers] pointed at this Loom
instance on port `8092`.
