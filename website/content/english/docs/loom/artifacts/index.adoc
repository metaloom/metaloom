Loom publishes JVM artifacts and container deployment assets separately.

== Maven Artifacts

See link:../maven-artifacts/[Maven Artifacts] for the BOM and the primary client and shared model modules.

== Containers

Loom ships as `metaloom/loom-server` (production) and `metaloom/loom-demo` (all-in-one). The AI agent's
coding sandbox additionally uses the `metaloom/loom-session-runner` image. See
link:../containers/[Containers] for the Docker / Compose examples and link:../../deployment/[Container Images]
for the full list. The agentic modules (`loom/agent/chat`, `loom/agent/memory`, `loom/agent/sandbox`)
are part of the server image and require no separate artifact.
