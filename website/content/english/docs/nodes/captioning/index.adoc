The captioning node generates a **natural-language caption** for an image using a vision-language
model — a short description of what the image shows.

++++
<div class="ml-nodeviz" data-nodeviz='{"kind":"captioning","applies":"Image","badge":"Vision model service","persist":"asset_json_comp + asset_node_result ledger","inputs":[{"t":"image","l":"image"}],"outputs":[{"t":"text","l":"caption_result","d":"one-sentence description"}]}'></div>
++++

[cols="1,3"]
|===
| Kind | `captioning`
| Applies to | Image (video / audio are stubbed / not yet implemented)
| Inputs | None
| Output keys | `caption_result` (String)
| Requirements | A vision-language model service reachable from the worker (configurable host/port). CPU on the worker; the model runs in the service.
| Persists to | `asset_json_comp` + `asset_node_result` ledger
|===

== Configuration

`CaptioningNodeOptions`:

[options="header",cols="1,2"]
|===
| Option | Meaning
| model host | Hostname of the vision-language model service
| model port | Port of the vision-language model service
|===

== Use Cases

* **Alt text / accessibility** — auto-generate descriptions for images.
* **Searchable descriptions** — index a caption per image for natural-language retrieval.
* **Cold-start metadata** — give newly ingested images a description before human review.
